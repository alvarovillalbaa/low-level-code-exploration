# Project scaffolding

Last updated: 2026-10-10

These three authoring assets belong to the shared experiment tooling. Copy the
README into a new experiment's `README.md`, merge the Makefile snippet into its
Makefile, and place `validate.sh` in that experiment's `scripts/` directory.
Replace the placeholders with the experiment's constraints and real validation.
The bundled shell script reports a placeholder; it does not prove an experiment.

Keep completed documentation and validation beside the experiment they describe.
